# 東京クリスマスマーケット2026 スノードームメーカー（テスト公開）

ガラスのスノードームを3Dで組み立てて、画像保存・SNSシェア・コンテスト投稿ができるWebコンテンツです。

- メーカー：`index.html`
- ギャラリー（コンテスト）：`gallery.html`
- 3D：three.js 0.160（jsdelivr）
- 投稿バックエンド：`gas/Code.gs`（Google Apps Script ウェブアプリ）

## コンテスト投稿の流れ

1. メーカーで「コンテストに投稿」→ 画像はGoogleドライブ、投稿情報はスプレッドシート（`posts` シート）に保存
2. 投稿は `status = pending`（非公開）で入る
3. 事務局がスプレッドシートの `status` を `approved` に変えるとギャラリーに掲載（`rejected` は非掲載）
4. いいねは1端末1作品につき1回（`likes` シートで管理し、件数は自動で再集計）

## GASを更新したとき

Apps Script エディタで「デプロイ → デプロイを管理 → 編集 → バージョン：新バージョン → デプロイ」。
URLは変わらないので `js/config.js` の書き換えは不要です。
